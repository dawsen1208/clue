# 新方向用户研究与任务测试 / Research and task-test plan

Status: proposal, not completed research. Obtain participant consent using the module's required procedure. Do not collect diagnoses, precise movement histories or unrelated personal information.

## 先验证什么 / Questions to investigate

1. 最近一次在校园找不到具体房间／设施是什么情形？最后如何解决？ / Describe the last time a specific campus place was difficult to find. How was it resolved?
2. 困难发生在建筑、入口、楼层、走廊还是门牌？ / Was the difficulty with the building, entrance, floor, corridor or door label?
3. 实际使用什么工具或线索？哪些有效、哪些缺失？ / Which tools or clues helped, and what was missing?
4. 找厕所时，距离、楼层、可进入性、设施类型哪个先影响决定？ / When finding a toilet, how do distance, floor, access and facility type affect the decision?
5. 对“有公开来源”“待核实”“近似距离”的理解是什么？ / What do source-linked, unconfirmed and approximate distance mean to the participant?
6. 什么情况下到楼提醒有帮助，什么情况下是打扰？可以如何控制？ / When would an arrival prompt help or interrupt? Which controls would be needed?

Avoid assuming everyone is lost, that indoor navigation is the preferred solution, or that an app is better than signs. Ask about recent behaviour before showing the concept.

## 问卷增补初稿 / Questionnaire additions

- Campus familiarity: first visit / under one term / one term–one year / more than one year.
- In the last four weeks, how often was a room or facility difficult to find? Never / once / 2–3 / 4+ / cannot recall.
- Which details were unclear? Building / entrance / floor / corridor / room label / opening or access / other / none. Multiple selection.
- What was the last consequence? No impact / extra time / late arrival / gave up / asked for help / other. Optional short example.
- How do you currently find nearby toilets? Signs / ask someone / university map / other map / familiar building / other / have not needed to.
- Which information would affect facility choice? Distance / same floor / adapted facilities / gender-neutral option / entry restrictions / opening information / other. Select up to three; no need to disclose a reason.
- Would a building-approach floor reminder be useful? Five-point scale plus not sure. Ask the reason.
- Preferred control: off by default / enable per destination / enable for selected places / other. Include permission and privacy explanation.

## Pilot / 小范围试填

Recruit 3–5 volunteers as a proposed convenience pilot, not a statistical sample target. Ask them to explain ambiguous terms, recall period and response choices. Record actual completion times and comprehension problems. Keep original question → observation → revised question → rationale. Do not fill in findings until the pilot has occurred.

## 可用性任务 / Usability tasks

| Task | Observation / Success indicator |
| --- | --- |
| Find ARTS 127 | Identifies building and notices floor is unconfirmed; does not invent a floor |
| Find Training Room 1 / 404 | Finds linked floor information and explains its verification limits |
| Find an adapted toilet from TLB | Sets reference origin and filter; identifies a listed candidate and checks access information |
| No match for a room | Understands the directory is incomplete and can recover without a false answer |
| Building check-in prompt | Understands manual versus GPS trigger; can snooze, mute or stop |
| Wrong place information | Downloads a local issue note and understands it was not submitted |

Record completion, wrong turns within the UI, help requests, uncertainty comprehension and perceived effort. Observe opt-in wording without requiring participants to share device location. Compare the new flow with existing university map/signage workflows rather than only asking whether the new design is attractive.
